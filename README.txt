UNDANGAN KHITANAN MUHAMMAD ABYAN HADE AL FATIH

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka folder undangan-khitanan-abyan di VS Code.
3. Jalankan index.html dengan ekstensi Live Server.
4. Pastikan koneksi internet aktif untuk Tailwind CDN dan Google Fonts.

ISI FOLDER
- index.html : struktur halaman undangan
- style.css  : desain dan animasi
- script.js  : countdown, musik, dan WhatsApp
- assets/foto-abyan.jpeg : foto yang diberikan
- assets/blue-instrumental.mp3 : musik instrumental yang diberikan

CATATAN
- Musik mulai setelah pengunjung menekan tombol "Buka Undangan", karena browser membatasi autoplay bersuara.
- Link Google Maps dan nomor WhatsApp sudah dipasang.
